
PC-LISP is meant to run on 32 & 64 bit Linux, Mac, & Windows.

Currently, the system has been tested on:

	64 bit Linux
	Mac (tested on Yosemite)
	Microsoft Windows

It should run fine on 32 bit Linux. 

To build on Linux or Mac:

	cd src
	make

On Windows with msys2 and ucrt64 do:

	cd src
	make -f Makeming64

Running the executable requires, that the *.dll of msys2 are in 
search path.

On Windows with msys2 and ucrt64, 
but without using regex, do:

	cd src
	make -f Makeming64noregex

On Windows with 32bit mingw,
but without regex, do:

	cd src
	make -f Makemingw32noregex

On Windows with MSC try:

	cd src
	nmake -f Makefile.msc

You will end up with a file name "pc-lisp" (or "PC-LISP.exe" on Windows).  
That is the system.
